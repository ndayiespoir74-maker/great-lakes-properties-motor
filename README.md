# Great Lakes Properties Motor

## About the Project
Great Lakes Properties Motor is a motor vehicle platform designed to help users view, search, and manage vehicles available for sale.

## Features
- View available vehicles
- Search for vehicles
- View vehicle details
- Manage vehicle listings
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Installation
1. Clone this repository.
2. Open the project in your development environment.
3. Configure the database.
4. Run the application.
